Zenith is a powerful CLI for habit tracking, task management, and project management.

Usage:
  zenith [command]

Available Commands:
  ai          AI powered productivity helper (Ollama / LM Studio)
  habit       Track and log daily habits
  project     Manage development projects
  summary     Show daily summary list
  task        Manage tasks and time logs
  timer       Manage and schedule task timers and reminders
  tui         Open the interactive TUI dashboard

Flags:
  -h, --help      help for zenith
  -v, --version   version for zenith

Everything you need to stay in the zone

No cloud, no trackers. Completely local, fast, and optimized for developers.

📝

Task Management

Add, prioritize, and structure tasks by projects. Complete tasks, apply colored tags, and track time spent on each activity.

🔄

Habit Building

Build consistency by tracking daily, weekly, or monthly habits. Log completed occurrences directly from the terminal.

🤖

Local AI Integration

Connects to local LLMs via Ollama or LM Studio. Analyze tasks and generate daily productivity suggestions or summaries locally.

🔔

Scheduled Timers

Set timed reminders for task sessions (Pomodoros, breaks, meetings). Receive native macOS desktop notifications and command line alerts.

📊

Interactive TUI

A full terminal UI built on Go Bubble Tea. Visualize tasks, view the date, track running timers, and view progress bars dynamically.

📜

Task History Log

Maintain a chronological audit history of all status changes, edit operations, and active timer sessions for every task.

Beautiful Terminal Dashboards

                    
Launch the interactive terminal dashboard by running zenith tui. Fully dynamic layout built using Bubble Tea and styled with Lipgloss, providing progress bars, date indicators, and ticking time tracking sessions in real time.

  • Real-time Timers: Watch your logged session hours, minutes, and seconds increment in the UI.

Install the Zenith CLI

            
Get started in seconds on macOS, Linux, or Windows.

            
            

                

                    
From Source (Go)

                    go install github.com/yalcinumutt/zenith-cli@latest
                

                

                    
Homebrew (macOS)

                    brew install yalcinumut/tap/zenith
                

            

            
            

                
Ollama & LM Studio AI Setup

                
Ensure you have Ollama or LM Studio running locally. Then set your preferred provider:

                

                    # For Ollama (default)

                    export ZENITH_AI_PROVIDER="ollama"

                    export ZENITH_AI_MODEL="llama3"


                    # For LM Studio

                    export ZENITH_AI_PROVIDER="lmstudio"

                    export ZENITH_AI_MODEL="meta-llama-3-8b-instruct"
